Deployment configs included in this repo
  • deploy/nginx/jan_drishti.conf - reverse proxy, upstream pool, limit_req, proxy_cache, stub_status
  • deploy/apache/jan_drishti.conf - balancer:// cluster, mod_qos/mod_ratelimit, mod_cache
  • deploy/iis/web.config - IIS + ARR server farm, dynamic IP restrictions, output caching, failed-request tracing
  • deploy/docker-compose.scale.yml - 4 replicas + Nginx balance with one command
  • deploy/kubernetes/jan-drishti.yaml - Deployment, HPA (CPU + custom req/s metric), Service, probes
  • scripts/start_cluster.py / .sh - launch N local replicas wired to each other
  • scripts/load_test.py - external load generator with a live throughput table
